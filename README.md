# Contract, AMC, Asset & Field Service Platform

Angular 22 frontend foundation for the B2B SaaS platform defined in the product SRS.

This repository currently contains the application skeleton only: architecture, routing, configuration, and tooling. Business screens are not implemented yet.

## Scripts

- `npm start` — development server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run format` — Prettier
- `npm test` — unit tests (Vitest)
